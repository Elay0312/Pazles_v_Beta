# 🧩 Пазлики - Игра-головоломка

Классическая игра в жанре "пазл", где вам предстоит собрать случайную картинку, меняя местами фрагменты изображения. Идеальный способ проверить внимание и пространственное мышление!

## 🎯 Особенности

- Случайный выбор картинки из папки с изображениями
- Сетка 5x5 фрагментов (настраивается)
- Система подсчёта перестановок
- Таймер для отслеживания времени сборки
- Визуальная индикация выбранного фрагмента
- Поздравление с победой при правильной сборке

## 🎮 Управление

| Действие | Управление |
|----------|------------|
| Выбор фрагмента | ЛКМ по фрагменту |
| Обмен фрагментов | ЛКМ по первому, затем по второму фрагменту |
| Отмена выбора | ЛКМ по выбранному фрагменту повторно |

**Механика игры:**
1. Изображение разрезается на сетку фрагментов (5x5 по умолчанию)
2. Фрагменты перемешиваются случайным образом
3. Ваша задача - поменять фрагменты местами, чтобы собрать исходную картинку
4. Выберите один фрагмент, затем другой - они поменяются местами
5. Игра засчитывает количество перестановок и время сборки
6. При полной сборке картинки появляется победное сообщение

## 📋 Требования

- Python 3.x
- Pygame
- Папка `Images` с изображениями
- Шрифт Minecraft (опционально, для отображения текста)

🎲 Игровая механика (подробно)
Структура пазла
По умолчанию используется сетка 5x5 фрагментов (25 фрагментов):

Количество строк: ROWS = 5

Количество столбцов: COLS = 5

Отступ между фрагментами: MARGIN = 2 пикселя

Вы можете легко изменить сложность, поменяв эти значения в коде!

Система выбора
Первый клик - выделяет фрагмент зелёной рамкой

Второй клик на другом фрагменте - меняет их местами

Второй клик на том же фрагменте - снимает выделение

Подсчёт статистики
Показатель	Описание
Количество перестановок	Счётчик обменов фрагментами (сбрасывается при новой игре)
Время	Количество секунд с начала игры (обновляется каждую секунду)
Победа
Когда все фрагменты встают на свои места (сравнение с оригинальным порядком), игра:

Отображает поздравление зелёным цветом

Показывает количество перестановок

Демонстрирует затраченное время

Игра продолжает работать (можно любоваться результатом)

🎨 Визуальные эффекты
Выделение фрагмента
Выбранный фрагмент обводится зелёной рамкой

Рамка отображается с отступом для наглядности

Интерфейс
Счётчик перестановок - внизу экрана (белый текст)

Таймер - в центре нижней части экрана

Победное сообщение - по центру экрана при победе
